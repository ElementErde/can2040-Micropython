# can2040 MicroPython Wrapper
This repository provides a MicroPython wrapper for the
[can2040](https://github.com/KevinOConnor/can2040) CAN controller on the
Raspberry Pi Pico. It includes a native C user module, an example
`main.py`, and a GitHub Actions workflow for building Pico firmware.
The wrapper exposes CAN startup, transmission, reception, and statistics
through the `can2040` MicroPython module.
